# Game Hunter AI V3 Android

This Android WebView app opens the owner's live Hatchable V3 web application at https://game-hunter-ai.hatchable.site. Requires internet access and Hatchable owner sign-in. It is a wrapper, not an offline native game database.

## Build
GitHub Actions > Build Game Hunter AI V3 APK > Run workflow, or push to main. Download the GameHunterAI-V3-Debug-APK artifact from the completed run. This is an unsigned-for-release **debug APK** for personal testing, not a Play Store production build.

Game research is informational; no real-money betting or automated wagering is included.
